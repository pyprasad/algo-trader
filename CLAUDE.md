## Plan & Review

### Before starting work
- Always in plan mode to make a plan
- After get the plan, make sure you Write the plan to .claude/tasks/TASK_NAME.md.
- The plan should be a detailed implementation plan and the reasoning behind them, as well as tasks broken down.
- If the task require external knowledge or certain package, also research to get latest knowledge (Use Task tool for research)
- Don't over plan it, always think MVP.
- Once you write the plan, firstly ask me to review it. Do not continue until I approve the plan.

### While implementing
-
You should update the plan as you work.
- After you complete tasks in the plan, you should update and append detailed descriptions of the changes you made, so following tasks can be easily hand over to other engineers.
- If you find any issues or need to change the plan, update the plan and ask for review.

### Project Overview
- The project aims to develop a multi-market trading system that leverages advanced strategies and real-time data to optimize trading performance.
- Key components include data collection, signal analysis, trade execution, and risk management.
- The system will be designed for scalability and flexibility, allowing for easy integration of new markets and strategies.
- User feedback and performance metrics will be continuously analyzed to improve the system over time.
- Comprehensive logging and monitoring will be implemented to ensure system reliability and facilitate troubleshooting.

### Goals
- Develop a robust and flexible trading system that can adapt to changing market conditions.
- Implement advanced trading strategies that leverage real-time data and analytics.
- Ensure high levels of system reliability and performance through comprehensive testing and monitoring.
- Continuously improve the system based on user feedback and performance metrics.
- Use advanced analytics and machine learning techniques to enhance trading strategies and decision-making.

### Key Components
- **Data Collection**: Implement real-time data collection from multiple markets, ensuring high availability and low latency.
- **Signal Analysis**: Develop algorithms for analyzing market signals and generating trading signals based on predefined strategies.
- **Trade Execution**: Create a robust trade execution engine that can handle high volumes of trades with low latency and high reliability.
- **Risk Management**: Implement risk management strategies to minimize potential losses and ensure compliance with trading regulations.
- **User Interface**: Design an intuitive user interface for monitoring and managing trades, with real-time updates and analytics.
- **Logging and Monitoring**: Establish comprehensive logging and monitoring systems to track system performance, detect anomalies, and facilitate troubleshooting.
- **Testing and Validation**: Implement rigorous testing and validation processes to ensure the reliability and accuracy of the trading system.
- **Documentation**: Maintain detailed documentation for all components, including setup instructions, usage guidelines, and troubleshooting tips.
